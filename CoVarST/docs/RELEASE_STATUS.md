## 核查范围

本轮重新执行了九个权重的完整真实特征切片推理，检查全部 10,000 基因、严格状态加载和精确的基因/参考顺序；记录见[核查报告](LOCAL_AUDIT.md)和[机器记录](../validation/chinese_release_recheck.json)。

软件检查覆盖导入、通用粗 ST 打包、外部 RNA 拒绝、全基因归一化、含未分配质量的守恒，以及带独立 SVD 对照的严格零空间投影。通用完整连接检查跑过秩 0 和 8，测试输入是明确的合成软件小样本。

没有重跑完整的 WSI 主干提取，也没有从原始 BayesTME 计数重训参考。任意粗 ST 适配器目前只有软件和输入规范层面的检查，不能继承独立生物学接受。新患者上的学生表现和细胞表达是否真实都需要另行验证。
