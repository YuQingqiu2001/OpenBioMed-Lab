# CoVarST 运行规范

动手前先读 [README.md](README.md) 和对应的方法、输入规范。检查 `models/manifest.json`，运行 `verify-assets`，并确认癌种标识选对。权重必须与对应的 Program 顺序、基因顺序和参考配套使用；推理阶段不要临时重建参考。

请使用已有的兼容环境。安装依赖或下载权重需要用户授权，本规范不授予发送消息、发布、外部上传或安装依赖的权限。`infer-spots` 只接收图像特征和坐标，不读取样本 RNA。第三方权重由用户从官方来源准备，并遵守各自的许可。

细胞重建只使用当前切片实测的粗 RNA 和真实配准细胞核。外部 scRNA-seq、既有的推断细胞表达，以及用于精细评估的 RNA，都不能参与拟合和选模。要保留物理捕获几何、五类图像的类别顺序、无核 spot 的未分配质量和全基因概率归一化。类内连续变化轴的秩不代表细胞类型数量。

输出写到新路径，记录输入哈希，检查完成标记和日志之后再报告完成。学生模型对教师集成的一致性，与原始教师的患者留一成绩分开汇报。计数守恒是核账结果，细胞表达是否真实需要独立验证。

命令见[使用指南](docs/QUICKSTART.md)、[H&E 推理](docs/HE_TO_SPOTS.md)、[参考构建](docs/REFERENCE_PROGRAMS.md)和[细胞重建](docs/SPOT_TO_CELL.md)。本地构建任务不会自动推送远端。
