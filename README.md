# OpenBioMed Lab

> 开放生物医学人工智能研究实验室 — 可复现、可分发、可协作的研究工具集合。

## 子项目

### 1. Literature Learning Suite `v1.3.0`

从研究问题到知识图谱的完整文献认知操作系统。

- S 级 7 层解剖协议 — 将论文转化为结构化知识图谱
- 5 策略语义关联引擎 — 基于 90,125 基因的自动关联
- 自动 IF 标注 — 内置 21,800 种期刊 JCR 2024 数据
- 10 维度质量自检 — 空壳检测、非法边过滤
- 7 种语言完整文档（中/英/德/日/韩/西/阿）

**快速开始：**
```bash
cd literature-learning-suite
pip install -r scripts/requirements.txt
python scripts/init_workspace.py
```
