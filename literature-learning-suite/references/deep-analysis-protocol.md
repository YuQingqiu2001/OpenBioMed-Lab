# Deep Analysis Protocol

## Evidence Ledger

Create a ledger before synthesis:

| Field | Content |
|---|---|
| Claim | Falsifiable statement |
| Evidence | Data, experiment, model, statistic |
| Location | Page, figure, table, section |
| Directness | Direct / indirect / contextual |
| Strength | High / moderate / low |
| Caveat | Bias, confounder, uncertainty |

## Mechanism Discipline

For each mechanism step, label:

- `shown`: directly tested.
- `supported`: multiple indirect observations.
- `borrowed`: established external knowledge.
- `hypothesized`: analyst extension.

A valid cascade does not require molecular detail when the study does not provide it. It is
better to preserve an unknown step than to manufacture a plausible pathway.

## Hidden Axes

Good hidden-axis observations are grounded in design:

- Spatial compartment emphasized or omitted.
- Time scale that determines the apparent effect.
- Selection criteria that define the population.
- Measurement modality that constrains interpretation.
- Intervention point that reveals causal assumptions.

Interpretations should be testable or at least falsifiable.

## Cross-Paper Synthesis

Compare papers using a matrix:

| Dimension | Paper A | Paper B | Interpretation |
|---|---|---|---|
| Population/model | | | |
| Exposure/intervention | | | |
| Endpoint | | | |
| Time point | | | |
| Assay | | | |
| Effect direction | | | |
| Bias/limitations | | | |

Do not call results contradictory until differences in these dimensions have been examined.
