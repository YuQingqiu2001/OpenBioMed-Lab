## 示例 1: 临床 III 期试验 — Dapirolizumab pegol (PHOENYCS GO)

**Lancet, IF 98.4, PMID:42214397**

### Tier 2: 5 子问题
1. Fab'-PEG 分子设计是否确实消除了 FcγRIIa 介导的血小板聚集？
2. CD40L 阻断在 SLE 中是否优于 B 细胞耗竭(rituximab)或 IFN 阻断(anifrolumab)？
3. CD40-CD40L 阻断是否会损害保护性抗体应答(疫苗/感染)？
4. CD40L 阻断是否对特定 SLE 亚型(狼疮肾炎/神经精神狼疮)更有效？
5. PEG 化 Fab'片段是否会诱导抗药抗体(ADA)？对长期疗效的影响？

### Tier 3: 5 C-E-S 链（不同角度）
1. **药物工程学**: 去除 Fc 段从根本上消除血栓栓塞毒性——理性药物设计范式
2. **免疫学**: CD40-CD40L 是 SLE 多种自身抗体谱系的统一上游驱动节点
3. **临床试验设计**: BICLA 作为主要终点反映从器官特异性向整体评估的范式转移
4. **历史教训**: SLE III 期试验成功率 ~50%——PHOENYCS GO 的设计从失败中学习
5. **协同机制**: CD40L 阻断联合标准治疗(HCQ+GC+MMF)的多通路协同

### Tier 4: 完整机制级联
```
凋亡清除缺陷→dsDNA 释放→BCR 识别→MHC-II 呈递→自身反应性 CD4+ T 细胞活化
→CD40L(CD154)瞬时表达上调→与 B 细胞 CD40 结合→TRAF2/6 招募→IKK→IκBα K32/K36 磷酸化
→NF-κB(p50/p65)核转位→BCL-XL/AICDA/IRF4→生发中心存活+CSR+SHM+浆细胞分化
→自身抗体(IgG 抗 dsDNA)→免疫复合物→肾小球沉积→FcγR+补体→肾炎
```
**4 个关键修饰位点**: IκBα K32/K36, p65 S536, AID S38, 血小板 FcγRIIa ITAM

### Tier 5: 隐藏组织轴
- **观察 1**: SLE 生物制剂靶点层级上升(B 细胞清除→B 细胞存活因子→IFN-I→T-B 共刺激)——靶点越上游覆盖面越广但安全性挑战越大
- **解读 1**: 免疫干预的"漏斗效应"——精准医学的出路在 biomarker 驱动的靶点分层
- **观察 2**: 第一代抗 CD40L 失败(2003-2006)几乎永久关闭此靶点——直到 Fab'-PEG 使其复兴
- **解读 2**: "靶点复兴(target resurrection)"是药物开发中被低估的创新模式

### Tier 6: 概念创新
- **新概念**: 靶点复兴、SLE 治疗三级火箭、Fab'-PEG 通用安全化平台
- **推翻旧观点**: "抗 CD40L 太危险不应再尝试"
- **方法学突破**: Fab'-PEG 化单抗平台

### Tier 7: 5 条跨文献关联
1. van Vollenhoven 同期述评(PMID:42214395)
2. Ruplizumab I/II 期(前代,2003-2006)
3. Belimumab BLISS-52/76(竞品,2011)
4. Anifrolumab TULIP-2(竞品,2019)
5. CD40-CD40L 基础生物学(van Kooten 2000; Langer 2005)

## 示例 2: 全球共识声明 — PMOS (PCOS 改名)

**Lancet, IF 98.4, PMID:42119588**

### 如何处理非实验研究

共识声明没有实验数据，但仍有丰富的可分析内容：

**Tier 3 C-E-S 链角度**:
1. **病理学准确性**: "囊肿"命名错误(实为未成熟窦卵泡)→误导临床实践
2. **因果方向**: IR→高雄激素→排卵障碍(非卵巢→全身)——名字必须反映因果
3. **方法论**: 14,360 人参与+Delphi+营销分析——前所未有的严谨性
4. **临床实践**: 命名推动妇科单学科→内分泌-代谢-心内-精神多学科协作
5. **实施科学**: "进化而非革命"策略——从激进改名失败中学习(AIDS/精神分裂症)

**Tier 4 机制级联**（基于 PCOS 病理生理，非共识本身）:
```
IR→高胰岛素→卵巢膜细胞 CYP17↑→雄烯二酮/睾酮↑+SHBG↓→游离睾酮↑
→GnRH 脉冲频率↑→LH/FSH>2:1→颗粒细胞芳香化酶↓→无排卵
```
**5 个修饰位点**: IRS-1 Ser312, CYP17A1, SHBG promoter, FSHR, Kisspeptin 神经元

**Tier 5 隐藏轴**: 专科碎片化(妇科看到卵巢/内分泌看到代谢/皮肤看到毛囊/精神看到情绪——无人看到完整患者)、命名影响研究资助、病理生理学命名 vs 公众可理解性的平衡

### 关键原则
- ✅ 共识声明的研究对象不是"生物机制"而是"命名如何影响认知/行为/结局"——用社会学+实施科学框架分析
- ✅ 机制级联基于该疾病已知病理生理(非共识本身)，标注"基于已知病理"
- ❌ 不要因为没有实验数据就跳过 Tier 4-7

## 示例 3: 前瞻性队列 — FLOW-CMD Registry

**Lancet, IF 98.4, PMID:42167298**

### 观察性研究的 S 级策略

**Tier 3 C-E-S 链**:
1. **患病率**: CMD 在连续造影患者中的真实患病率(系统性筛查消除选择偏倚)
2. **独立预测**: CMD→MACE 独立于 FFR(冠脉串联阻力模型 R1+R2)
3. **双重缺血**: 心外膜固定+微血管动态→叠加→MACE(解释 PCI 后持续心绞痛)
4. **临床可行性**: FLOW-CMD protocol 作为导管室模板(5764 筛查→1003 入组)
5. **可治疗性**: CMD 是独立疾病实体非垃圾桶诊断(RhoK 抑制剂/内皮素拮抗剂)

**Tier 4 机制级联**: 5 步内皮→平滑肌→纤维化→稀疏→微栓塞级联，4 个修饰位点(eNOS S1177, CaV1.2, TGF-βRII, Titin)，3 个反馈环

## 示例 4: bioRxiv 预印本 — 线粒体-免疫轴→AD

**bioRxiv, BIORXIV:10.64898/2026.06.03.729900**

### 预印本 S 级策略

预印本只有摘要。**不因信息不足而降低标准**——利用已有的领域知识进行推理，标注 UNCERTAIN。

**Tier 3**: 5 C-E-S 链（基于摘要+mtDNA-cGAS-STING 领域知识推理）
1. 线粒体功能障碍→"必要不充分"条件(双重打击模型)
2. mtDNA 释放→cGAS-STING→IFN 轴(分子触发器)
3. IFN→小胶质细胞→C1q/C3→突触修剪(补体介导)
4. 增强线粒体自噬→减少 DAMP 产生(治疗策略)
5. 脑衰老→AD 的"拐点"(临床监测窗口)

**Tier 4**: 7 步完整机制级联(mtDNA 漏出→cGAS→cGAMP→STING→TBK1→IRF3→IFN→小胶质→突触修剪)，含 4 个修饰位点

**Tier 5**: 跨学科概念融合(线粒体生物学+先天免疫学交界→此前未被认识)

**标注**: 每条链的 UNCERTAIN 反映预印本的局限性，但不影响分析的完整性
